# Daily Development Workflow

> A structured daily routine for consistent, safe AI-assisted engineering.
> Generated by ai-workspace.

---

## Morning Setup (5 min)

1. **Pull latest changes:** `git pull origin main`
2. **Review open issues / PRs**
3. **Check CI status** — is main green?
4. **Set today's focus:** One clear goal for the session.
5. **Start one AI agent at a time** — do not run multiple heavy tools simultaneously.

---

## Working Session

### Before Starting a Task
- [ ] Is the task clearly scoped? (if not, write a 2-line description first)
- [ ] Is there an existing test covering this area? (understand before editing)
- [ ] Do you have the right tool? (see MCP_AND_AGENT_SETUP.md)

### While Working
- Work in small, reversible commits
- Run tests after each meaningful change
- Use `git diff` before staging — never `git add .` blindly
- If an AI agent makes changes, review them before accepting

### Before Stopping
- [ ] All tests pass locally
- [ ] Changes committed with a clear message
- [ ] Nothing sensitive in staged/committed files
- [ ] PR or branch pushed if work is complete
- [ ] Stop any heavy background processes (see stop-heavy-tools.ps1)

---

## AI Agent Discipline

- Run **one heavy AI agent at a time** (Codex, Gemini, Claude, etc.)
- Use Antigravity/Gemini for analysis, Codex for implementation
- Always review AI-generated code before committing
- Do not accept AI changes that touch `.env`, secrets, or infrastructure files

---

## End-of-Day Checklist

- [ ] All work is committed (no uncommitted local changes you cannot recreate)
- [ ] CI is passing on your branch
- [ ] Background tools stopped
- [ ] Notes on tomorrow's tasks written down

---

## Weekly Maintenance

- Review and update `docs/ROADMAP.md`
- Run `npm audit` and `pip audit` on active projects
- Review open GitHub issues and PRs
- Rotate any credentials that are more than 90 days old
