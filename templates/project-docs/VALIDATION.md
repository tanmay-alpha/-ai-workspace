# Validation Guide

> How to validate changes to this project before committing or deploying.
> Generated by ai-workspace.

---

## Local Validation Workflow

### 1. Syntax and Compile Check

```bash
# Python projects
python -m compileall . -q

# Node projects
npx tsc --noEmit   # if TypeScript
```

### 2. Run Tests

```bash
# Python
pytest tests -q --tb=short

# Node
npm test

# With coverage
pytest tests --cov=src --cov-report=term-missing
```

### 3. Lint

```bash
# Python
ruff check .
flake8 .

# Node
npm run lint
```

### 4. Secret Scan

```bash
# Install gitleaks
# https://github.com/gitleaks/gitleaks

gitleaks detect --source . --verbose
```

### 5. Dependency Audit

```bash
# Python
pip audit

# Node
npm audit
```

---

## CI Validation

All of the above are run automatically in GitHub Actions on push and pull request.

Check `.github/workflows/ci.yml` for the exact commands used in CI.

---

## Pre-Push Checklist

- [ ] Tests pass locally
- [ ] No new secrets committed (`git log --all -p | grep -i 'api_key\|password\|secret'`)
- [ ] `.env` is NOT tracked (`git ls-files .env` returns nothing)
- [ ] CI passes on your branch

---

## When CI Fails

1. Read the full error log — do not guess.
2. Reproduce locally before fixing.
3. If it is a flaky test, document it before ignoring it.
4. Never skip CI to unblock yourself unless authorized.
