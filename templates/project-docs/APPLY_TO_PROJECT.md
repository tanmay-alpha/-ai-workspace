# How to Apply ai-workspace to a Project

> Step-by-step guide to applying ai-workspace templates, CI, and context to any existing project.
> Generated by ai-workspace.

---

## Option A: One Command (Recommended)

```powershell
powershell -ExecutionPolicy Bypass -File scripts\apply-ai-workspace.ps1 `
  -ProjectPath "C:\path\to\your-project" `
  -Preset auto `
  -IncludeCI `
  -IncludeSecretScan `
  -IncludePrompts `
  -IncludeDocs `
  -GenerateProjectMap `
  -IncludeADR `
  -IncludePRD `
  -IncludeRoadmap `
  -IncludeAgentRules `
  -IncludeGitHubTemplates `
  -Backup
```

This will:
1. Detect your project type automatically
2. Generate a tailored CI workflow
3. Copy security and prompt templates
4. Add ADR, PRD, Roadmap starters
5. Generate PROJECT_MAP.md
6. Back up any existing files before overwriting

---

## Option B: Step by Step

### Step 1: Detect Your Project

```powershell
powershell -ExecutionPolicy Bypass -File scripts\detect-project.ps1 -ProjectPath "C:\path\to\project"
```

Review the output. Check the detected type and preset recommendation.

### Step 2: Generate Project Map

```powershell
powershell -ExecutionPolicy Bypass -File scripts\generate-project-map.ps1 -ProjectPath "C:\path\to\project"
```

This creates `PROJECT_MAP.md` — the primary context file for AI agents.

### Step 3: Generate CI

```powershell
powershell -ExecutionPolicy Bypass -File scripts\generate-ci.ps1 -ProjectPath "C:\path\to\project" -DryRun
# Review output, then run without -DryRun
powershell -ExecutionPolicy Bypass -File scripts\generate-ci.ps1 -ProjectPath "C:\path\to\project"
```

### Step 4: Copy Templates

Copy from `templates/project-docs/`, `templates/prompts/`, `templates/agent-rules/` as needed.

---

## After Applying

1. Review all generated files — do not blindly commit AI-generated content.
2. Run: `git diff --stat`
3. Run a secret scan: `gitleaks detect --source .`
4. Run: `powershell -ExecutionPolicy Bypass -File scripts\doctor.ps1 -ProjectPath "C:\path\to\project"`
5. Commit: `git add -p` (stage selectively)

---

## Rollback

If you want to undo changes:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\rollback-ai-workspace.ps1 `
  -ProjectPath "C:\path\to\project" -List
```

Then restore a specific backup.
