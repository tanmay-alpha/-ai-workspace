# Security Checklist

> Run this checklist before any production deployment or code review.
> Generated by ai-workspace.

---

## Pre-Commit Security Checks

- [ ] No hardcoded API keys, passwords, or tokens in source code
- [ ] No `.env` file committed to git (`git ls-files | grep -i .env`)
- [ ] No private keys, certificates, or `.pem` files committed
- [ ] `.gitignore` covers: `.env`, `*.pem`, `*.key`, `secrets/`, `credentials/`
- [ ] Secret scanning workflow is active (Gitleaks / GitHub Secret Scanning)

---

## Dependency Security

- [ ] Dependencies are pinned to specific versions (not `*` or `latest`)
- [ ] Known vulnerable packages identified (`pip audit`, `npm audit`)
- [ ] Dependencies reviewed for transitive risk
- [ ] Lock files committed (`package-lock.json`, `poetry.lock`, etc.)

---

## API and Authentication

- [ ] All endpoints require authentication (no unprotected admin routes)
- [ ] Authentication uses standard libraries (JWT, OAuth2) — not homegrown
- [ ] Rate limiting applied to authentication endpoints
- [ ] Tokens expire and are rotatable
- [ ] Passwords are hashed with bcrypt/argon2 (never MD5/SHA1)
- [ ] CORS is configured explicitly (not `*` in production)

---

## Input Validation

- [ ] All user inputs are validated and sanitized server-side
- [ ] SQL queries use parameterized statements (no string interpolation)
- [ ] File upload types and sizes are validated
- [ ] No raw `eval()` or `exec()` on user input

---

## Infrastructure

- [ ] No production secrets in CI/CD environment variables visible in logs
- [ ] Database is not publicly accessible
- [ ] Admin interfaces are not publicly accessible
- [ ] TLS/HTTPS enforced in production
- [ ] Sensitive logs are not stored (no passwords, tokens in logs)

---

## Trading / Financial Systems (if applicable)

- [ ] `TRADING_MODE=PAPER` is default in all non-production environments
- [ ] Order-placing code requires explicit `TRADING_MODE=LIVE` flag
- [ ] CI/CD never runs with live broker credentials
- [ ] Risk limits are validated before any order submission
- [ ] All trades are logged with timestamp, symbol, side, quantity, price

---

## Agentic AI Systems (if applicable)

- [ ] No live API keys embedded in agent prompts or tool definitions
- [ ] Agent tool permissions are scoped to minimum necessary
- [ ] Agent cannot autonomously commit to git without human review
- [ ] Agent cannot autonomously send emails or messages
- [ ] Agent actions are logged and auditable
